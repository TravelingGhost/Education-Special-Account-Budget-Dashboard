## 📝 프로젝트 소개
이 프로그램은 예산현액을 한눈에 파악할 수 있도록 도와주는 대시보드입니다.

## 📦 제공 버전 안내 (Releases에서 다운로드)
사용자 환경에 맞춰 두 가지 버전을 제공하고 있습니다. Releases 메뉴에서 압축 파일(`.zip`)을 받아주세요.

### 1. 일반용 (전체 기능)
* **파일명:** `예산현액_대시보드_날짜.zip`
* 모든 프로그램 환경이 포함되어 전체 기능을 쓸 수 있는 버전입니다.
* **사용법:** 압축을 완전히 푼 뒤, 폴더 안의 실행 파일을 더블클릭하여 엽니다.

### 2. HTML용 (간소화 버전)
* **파일명:** `예산현액_대시보드_HTML_날짜.zip`
* 별도 프로그램 없이 크롬(Chrome), 엣지(Edge) 등 웹 브라우저에서 가볍게 확인하는 버전입니다.
* **사용법:** 압축을 풀고 `예산현액_대시보드.html` 파일을 더블클릭하여 엽니다.

## ⚠️ 주의사항
* 다운로드한 파일은 **반드시 압축을 완전히 해제한 후에** 실행하셔야 정상 작동합니다. (압축 프로그램 안에서 바로 열지 마세요.)
* 일반용 실행 시 윈도우 PC 보호 알림이 뜬다면 **[추가 정보] → [실행]**을 눌러 진행해 주시면 됩니다.
